# crypto-metrics

用户自己维护的指标看板。数据是用户私人的判断依据，回答时以数据为准，不要用公开行情常识替代或"修正"这些指标。

## 取数

所有数据都通过本 skill 目录下的脚本获取（Node 18+，无依赖），输出为 JSON：

```bash
node <本skill目录>/scripts/cm.mjs <命令> [参数]
```

| 命令 | 用途 |
|---|---|
| `signals [--date YYYY-MM-DD]` | 做多/做空信号及原因（默认最新一期）。问"今天有什么信号"时先用它 |
| `latest` | 最新一期全部币种指标 + 信号 + 流动性 + 期权调参（约 40+ 个币，输出较大） |
| `date YYYY-MM-DD` | 指定日期的全部币种指标，结构同 `latest` |
| `coin SYMBOL [--days 30]` | 单币历史指标序列，以最新有数据日期为终点 |
| `dates [--limit 30]` | 有数据的日期（新→旧）；指定日期前先查，非每天都有数据 |
| `liquidity [--days 14]` | 资金流动性历史 |
| `volatility` | BTC 实现波动率(RV) vs 隐含波动率(DVOL) |
| `klines SYMBOL [--interval 1d] [--limit 60]` | K 线，周期 1h / 4h / 1d |
| `notifications [--limit 30] [--unread]` | 看板通知（新→旧，最多 100 条）；读取不会标为已读 |

需要的环境变量：`CRYPTO_METRICS_URL`（看板地址）和 `CRYPTO_METRICS_TOKEN`（看板 Admin 设置 → Agent 访问 里生成，`cmagent_` 开头）。脚本报缺少环境变量时，告诉用户去哪里生成和配置，不要尝试别的方式取数。

注意：
- 最新数据日期不一定是今天。回答里始终写明数据对应的日期。
- 脚本只读；Token 只能访问行情、指标和生成者账号的通知。遇到 401 说明 Token 失效、被吊销或生成它的管理员账号已不可用，403 说明接口不在只读白名单内。

## 字段

`latest` / `date` 中每个币：

- `otc` 场外指数；`otcChangePct` 较上一期变化 %；`prevOtc` 上一期值
- `explosion` 爆破指数；`explosionChangePct`、`prevExplosion` 同上
- `schelling` 谢林点
- `phase` 进场第 N 天 / 退场第 N 天 / 中性
- `periodQuality` 周期质量：高质量进场 / 低质量进场 / 高质量退场 / 低质量退场 / 待观察 / 数据不足
- `nearThreshold` 正在逼近关键阈值
- `momentum` 动能标记（见下）
- `riskNotes` 系统风险提示
- `signal` 系统已计算好的策略信号：`direction`(long/short/neutral)、`label`、`reasons`、`warnings`

`liquidity`：`btc` / `eth` / `sol` / `totalMarket` 为资金变化，单位亿美元，正为流入、负为流出；`comments` 为当日资金方向评论；`dailyReminder` 为当日提醒原文。

`notifications`：生成 Token 的管理员账号收到的通知（由 Telegram 机器人在数据更新后写入）。每期数据摘要是一条（标题形如「数据摘要 · 数据日期」），`date` 是数据日期；`groups` 列出这一期命中的分组，每组有自己的 `category`、`priority`、`coins`，整条的 `category` / `priority` 取最高优先级那一组。`category` 为 market 市场 / quality 周期质量 / strategy 策略信号 / momentum 动能 / favorite 收藏币种 / system 系统；`priority` 为 normal（机会类）/ high（跌破 200、进入退场期、短期撤出、三连降等风险）/ critical（用户收藏的币种出现风险）；`coins` 为该条涉及的全部币种（只涉及一个时 `coin` 也会给出）；`read` 表示用户在看板里是否已读。通知是事件提醒，具体数值以 `latest` / `coin` 的指标为准。

`optionTuning`：当期期权调参（delta 目标、vega 目标、策略），`rawText` 为原文。

## 解读规则（来自看板本身的定义）

**场外指数**：衡量场外交易活跃度。1000 是重要临界值——高于 1000 是最后一次加仓的时机，之后考虑何时盈利退出；低于 1000 表示拉盘资金阻力大于动力，难以形成新高突破。

**爆破指数**：反映大幅波动风险。低于 200 为风险区间，可能有较大下跌风险；高于 200 通常视为安全区间。由负转正时基本都可以在合适位置抄底；爆破转正和进场开始都是抄底、加仓的好时机。

**谢林点**：市场共识价格，即多数交易者认为合理的价格水平。

**进/退场期**：进场期适合买入，退场期适合卖出，数字是当前阶段持续天数。

**周期质量**（只比较关键节点的场外指数）：
- 进场期相邻关键节点持续抬升为高质量；持平、下降或反复为低质量
- 退场期相邻关键节点持续下行为高质量；持平、上升或反复为低质量
- 缺少可比较的关键节点时为待观察
- 进场首日爆破高于 200 只作为短线偏热提示，不改变周期质量
- 进场满一周后，若首周未跌回 200 且爆破均值走弱，直接下调为低质量进场
- 低质量意味着周期更容易缩短

**策略信号**（`signal` 已按下列规则算好，直接引用，不要自行重算）：
- 做多：场外指数连续 3 天大于 1000 且上升；或爆破指数负转正；或进场期第一天
- 做空：场外指数连续 3 天下降；或爆破指数跌破 200 且处于低质量进场；或退场期第一天
- 同时命中时优先级：做空触发 > 做多触发 > 三连升/三连降
- 无信号时为"观望"；爆破低于 200 时为"风险注意"

**动能标记**：`$` 向上动能强劲、重点关注；`*` / `※` 高速油门期（爆破>200）；`‼` 短期撤出信号（爆破跌破 200）；`↑` 连续上涨、进入上升通道；`w` 巨头犹豫（退场期特殊情况）。

## 回答方式

- 先给结论，再列支撑数据（日期、数值、变化），引用 `signal.reasons` 说明信号来源。
- 对比或复盘时用 `coin` / `date` 取历史，不要凭记忆补数。
- 数据只描述指标状态；是否下单、仓位多少由用户决定，不替用户做交易决定。
